# 🍔 Food Management System

A Java-based Food Management System that allows users to manage food items, place orders, and maintain food inventory efficiently. This project demonstrates Object-Oriented Programming (OOP), Collections Framework, File Handling, and Database concepts in Java.

---

#  Features

* ✅ Add New Food Items
* ✅ Update Food Details
* ✅ Delete Food Items
* ✅ Search Food by Name
* ✅ View Complete Menu
* ✅ Place Food Orders
* ✅ Calculate Total Bill
* ✅ Inventory Management
* ✅ User-Friendly Console Interface

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/your-username/FoodManagementSystem.git
```

### Navigate to Project

```bash
cd FoodManagementSystem
```

### Compile

```bash
javac Main.java
```

### Run

```bash
java Main
```
